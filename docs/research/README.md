# Research notes

Write one file per feature, `research/<feature>.md`, **before** building anything non-trivial. Template:

```
# <Feature>, researched YYYY-MM-DD
## Spec: what EPUB defines (links)
## Prior art: how Apple Books / Kobo / Thorium / Foliate / Readest do it (verified, with sources)
## Options: 2–3 approaches with tradeoffs
## Recommendation: plus what we'd skip for v1
```
